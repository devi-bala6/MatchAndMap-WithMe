Figure 1: Complete System Architecture Diagram System Architecture

System Architecture Specification: 4-Tier Layered Architecture with Complete Application Directory

The Match&Map with me software platform is organized into 4 cohesive architectural tiers: 1. Presentation Tier (Frontend Client): Contains all 15 application views: Landing Page, Auth (Login/Register), Dashboard, Profile & KYC, My Trips, Browse Trips, Day-Wise Itinerary, MapView, Buddies (Matching), Chat, Recommendations, Reviews, SOS Emergency Console, Weather, and Admin Dashboard. 2. Application Tier (Backend Server): Node.js & Express.js controllers: authController (JWT, bcrypt, KYC), socialController (40/30/30 matching algorithm, chat), tripController (trip slots, itinerary planner), safetyController (SOS alerts, GPS dispatch), and adminController (user moderation). 3. Data Persistence Tier: MongoDB Atlas cloud database storing collections for users, trips, connections, messages, reviews, and safety logs with local storage fallback. 4. External Services Tier: Integrations with Google Maps Platform, OpenWeatherMap API, SMS Gateways, Aadhaar KYC Verification APIs, and HTML5 Geolocation sensors.
