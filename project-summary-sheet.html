Project Title: Match&Map with me – Travel Companion Matching & Safety Platform
Project Code: CS705PC Batch Size: 04 Batch: 2023-27
Domain / Area: Web Application Development & Intelligent Matching Systems
Abstract:
(With Key Words) 		Match&Map with me is a comprehensive web application designed to help travelers find compatible travel companions based on their destination, travel dates, budget range, interests, and travel style. The system utilizes a weighted multi-factor matchmaking algorithm to calculate real-time compatibility scores and recommend the most suitable travel buddies. Key integrated features include interactive route mapping via Google Maps API, destination weather forecasting via OpenWeather API, day-wise itinerary scheduling, carbon footprint estimation for eco-conscious travel, and real-time in-app group messaging. To enhance traveler safety, the application incorporates an Emergency SOS alert system featuring an acoustic alarm siren, visual strobe beacon, and automated SMS dispatch with live GPS coordinates to designated emergency beneficiary contacts. The proposed platform aims to make solo and group travel safer, more economical, and collaborative.

Keywords: Travel Companion Matching, Multi-Factor Compatibility Scoring, Google Maps API, OpenWeather API, Emergency SOS Alert, Live GPS Tracking, Eco-Travel Score, Real-Time Chat, MongoDB, React 19, Full-Stack Web Application.

Architecture Diagram Methodology
The system implements a client-server architecture powered by a weighted multi-factor matching methodology.

1. User Profile Preprocessing: User attributes (budget range, travel style, destination interests) are encoded into normalized preference vectors.
2. Compatibility Scoring: The matching engine applies a weighted algorithm comparing shared interests (40%), budget compatibility (30%), and travel style alignment (30%) to generate dynamic 0–100% compatibility scores.
3. Live Navigation & Safety Protocol: Integrates Google Maps and OpenWeather APIs for interactive routing and forecast alerts. In emergencies, the SOS module captures device GPS coordinates and triggers automated SMS broadcasts to designated beneficiary contacts.
