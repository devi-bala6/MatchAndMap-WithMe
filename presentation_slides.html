ABSTRACT

Our system combines traveler preferences including destination, travel dates, budget category, travel style, and shared interests to recommend compatible travel companions. The collected information is analyzed using a multi-factor compatibility algorithm that scores each candidate buddy from 0% to 100%.

The platform features an integrated interactive route map powered by Google Maps API, destination weather forecasting via OpenWeather API, and day-wise itinerary management. To ensure traveler safety, an Emergency SOS system triggers an audio siren, strobe screen, and automated SMS alerts with live GPS coordinates to designated emergency contacts. Overall, the platform makes solo and group travel safer, economical, and collaborative.

Keywords: Travel Companion Matching, Multi-Factor Compatibility Scoring, Google Maps API, Emergency SOS Alert, Live GPS Tracking, React 19, MongoDB.

INTRODUCTION

Solo traveling has become increasingly popular due to flexible remote work and tourism trends. However, it presents major challenges:

  • Difficulty finding like-minded and trustworthy travel companions
  • High single-occupancy lodging and transit expenses
  • Safety and security vulnerabilities, particularly for solo female travelers
  • Disconnected tools across maps, weather forecasts, chat, and itineraries

Traditional travel groups rely solely on manual message boards, leading to high cancellation rates and personality mismatches.

This highlights the need for a unified travel companion matching platform with integrated navigation and emergency safety protocols.

EXISTING SYSTEM

Features
  • Uses unstructured social media groups (Reddit, Facebook, WhatsApp).
  • Manual negotiation of dates, budgets, and itineraries.
  • Requires switching across multiple separate apps for chat, maps, and weather.
Limitations
  • No automatic compatibility matching.
  • High risk of personality and budget mismatches.
  • No built-in emergency SOS or distress alert infrastructure.
  • No live GPS coordinate telemetry dispatch to guardians.
  • High failure and cancellation rate for planned trips.

PROPOSED SYSTEM

The proposed system:
  • Calculates 0–100% compatibility scores using multi-factor preference matching.
  • Renders interactive routes and waypoints using Google Maps API.
  • Provides destination weather forecasts via OpenWeather API.
  • Enables in-app group messaging and day-wise itinerary planning.
  • Dispatches instant Emergency SOS alerts with live GPS coordinates to guardians.
Benefits
  • Higher companion compatibility and reduced trip conflicts
  • All-in-one centralized travel workspace
  • Enhanced physical safety for solo travelers
  • Cost savings through shared group accommodation and transit
  • Carbon footprint awareness for eco-friendly travel

IMPLEMENTATION (MATCHING ALGORITHM)

// Multi-Factor Compatibility Formula export function calculateCompatibility(user, candidate) { let score = 50; // Baseline score // 1. Shared Interests (+25 pts max) const sharedInterests = candidate.interests.filter( i => user.interests.includes(i) ); score += Math.min(25, Math.round( (sharedInterests.length / 5) * 25 )); // 2. Budget Alignment (+12 pts) if (candidate.budget === user.budget) { score += 12; } // 3. Travel Style (+12 pts) if (candidate.travelStyle === user.travelStyle) { score += 12; } // Clamped output: 55% to 99% return Math.min(99, Math.max(55, score)); }
Explanation:

Multi-Factor Weighted Scoring Engine:

  • Base Score: Standardized baseline of 50 points.
  • Interest Overlap (40% weight): Proportional bonus up to 25 points.
  • Budget Match (30% weight): +12 points for identical budget category.
  • Travel Style (30% weight): +12 points for aligned pace.
  • Output: Returns dynamic compatibility percentage clamped between 55% and 99%.
